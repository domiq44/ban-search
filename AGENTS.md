# Consignes pour les tests

- Les tests unitaires doivent suivre la structure AAA : `Given`, `When`, `Then`.
- Chaque méthode d'une classe de test doit être précédée d'un commentaire qui explique ce qu'elle fait.
- Les valeurs attendues doivent être définies comme constantes dans le bloc `Given`, puis réutilisées dans les assertions du bloc `Then`.
